## 📈 Understanding Holographic Representation

This software uses 2D Gaussian functions to map visual information. Researchers use this method to ensure smooth transitions between light points in a hologram. By using complex-valued math, the software captures both the magnitude and phase of light. This produces clearer images than older, simpler methods.

The interface gives you control over the density of Gaussian points. Higher density settings produce results with more detail but require more processing power. Adjust these sliders to reach the balance that fits your computer hardware. 

The software generates the hologram data in real time. You see the outcome in the preview window as the computer processes the image. This feedback lets you adjust your variables to see how they change the final appearance of the hologram.

Your exported files save in a standard format compatible with common holographic display systems. Use the settings menu to change the output resolution if you need specific dimensions for your display.
